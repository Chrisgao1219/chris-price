🎯 这个系统是什么

自动监控 Meepo / Joyor / GPD / Kukirin 四个竞品品牌的价格、库存、上新与页面变化， 实时推送到飞书群，支持 @机器人 中文问答；本页面展示抓取到的多品牌价格矩阵与「我方 vs 竞品」价差。

品牌覆盖监控站点价格视角
Meepo24 款官方主站 + 欧洲站USD / EUR
Joyor官方 + 第三方渠道官方站 + geekbuying/banggood 等EUR
GPD38 款 × 3 国（每配置独立）gpd-minipc + gpdstoreUSD / GBP / EUR
Kukirin288 条 × 4 国欧洲/英国/美国/波兰多渠道EUR / GBP / USD / PLN

👀 本页面怎么看

顶部按 品牌 / 市场 / 货币 筛选；价格矩阵每行一个型号， 我方站点标「我方」，竞品价格与己方对比显示 ↑/↓ 百分比； 底部「价格洞察」给出最低价网站、己方排名、价差最大型号等结论。

⚠️ 提醒时效：价格最长延迟 1 天（每天抓一次）；大范围价格波动先怀疑抓取源临时异常，点产品链接核实。
